# Lumen Diary

Личный дневник, который превращает день в открытку: текст, фотографии и песня одного дня становятся одним визуальным воспоминанием с коротким названием. Открытка сохраняется в папку дня и возвращается из архива.

Команда Kernel, трек ArtTech (Make the Invisible Visible), Genesis Hackathon 2026.

**Живой прототип:** https://lumen-diary.onrender.com
Первый запуск после простоя может занять около минуты.

## Как проверить

1. Откройте https://lumen-diary.onrender.com.
2. В архиве три дня: «День, парк и солнце», «Ночь, офис и город», «Утро, чай и дождь».
3. Откройте любой день: проявка открытки, блок «Почему так» (цвет, фактура, композиция, движение), плеер песни.
4. Создайте свой день: текст, фото (1–5 JPEG/PNG/WebP), погода, ссылка на песню Spotify или YouTube, фраза о звучании. Открытка появится в архиве.

## Запуск локально

Нужны Python 3.11 и Node.js 22 (для сборки фронтенда).

Одной командой через Docker (из корня репозитория):

```bash
docker build -t lumen-diary .
docker run -p 8000:8000 -v lumen-data:/data lumen-diary
```

Откройте http://localhost:8000.

Без Docker (две команды, из корня):

```bash
cd frontend && npm ci && npm run build
cd ../backend && pip install -r requirements-dev.txt && DATA_DIR=./data uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000. Подробности и тесты: `backend/README.md`, `docs/deploy.md`.

Тесты (из `backend/`): `python -m pytest -q`, 260 тестов.

## Принципы

- **Всё детерминировано.** Одинаковый ввод даёт одинаковую открытку. Тесты: `test_same_input_gives_same_visual`, `test_deterministic`.
- **Музыка влияет на изображение.** Темп задаёт ритм проявки и шаг фото, энергия — размах линии, лад — характер движения. Песня не скачивается и не анализируется: параметры оцениваются по фразе пользователя или выбираются вручную, и интерфейс это показывает.
- **ИИ и внешние API не используются.** Визуал рисуется кодом (SVG, CSS, Canvas, Pillow).
- **Доступность.** `prefers-reduced-motion` отключает движение, сцена и цвета остаются. Контраст текста выше 4.5:1.

## Ограничения

- Пользователей и аккаунтов нет: все дни видны каждому, кто открыл сайт.
- На бесплатном хостинге диск не сохраняется между перезапусками и деплоями.
- Заголовки строятся по словарю: редкое слово вне словаря может остаться в падежной форме.
- Озвучка записи зависит от голосов браузера.
- Плееры Spotify и YouTube работают только по ссылке и доступны при наличии интернета.
