# Lumen Diary

Lumen Diary — личный дневник команды Kernel для ArtTech Genesis Hackathon. Проект превращает текст, фотографии и музыку одного дня в открытку-воспоминание, которую можно снова открыть из архива.

Веб-клиент на React и сервер на FastAPI разрабатываются в отдельных ветках. Инструкции по их запуску появятся вместе с соответствующими частями проекта.
