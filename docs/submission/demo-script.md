# Сценарий видео (до 3 минут)

Видео: `docs/submission/media/demo.mp4` (83 секунды, 1280 × 800, без звука). Записано автоматически через Playwright на чистом запуске с тремя демо-днями (`backend/scripts/seed_demo_days.py`). Ниже — что идёт в кадре и что можно наговорить поверх.

| Время | В кадре | Что говорим |
|---|---|---|
| 0:00–0:20 | Экран «Новый день»: пишем вечер с дождём и чаем, добавляем два фото, выбираем «Дождь», место «Дом», ссылку на YouTube и фразу «медленная, грустная, с пианино» | «Пишу день, добавляю фото и песню. Темп и настроение система оценит по фразе о звучании, погоду я выбрала сама.» |
| 0:20–0:28 | «Проявляем открытку…» → открытка проявляется: буквы по одной, фото по одному на удар, линия прорисовывается | «Открытка проявляется в ритме песни: медленная песня — длинная проявка.» |
| 0:28–0:45 | Название «Вечер, чай и дождь», папка дня `2026-11-22 Вечер, чай и дождь`, песня с плеером | «Название и папку дня система придумала сама.» |
| 0:45–0:58 | «Почему так»: Цвет и свет → Фактура → Композиция → Движение; на открытке подсвечиваются нужные слои | «Каждый параметр объяснён правилом и показан на самой открытке.» |
| 0:58–1:03 | «Проявить заново» | — |
| 1:03–1:12 | Архив: месяцы, отпечатки оживают при наведении | «Все дни в архиве; открытка оживает, если навести на неё.» |
| 1:12–1:23 | Три демо-дня: «День, парк и солнце», «Ночь, офис и город», «Утро, чай и дождь» | «Тёплый медленный мажор, плотная быстрая ночь, дождливое утро в миноре — одна система, три разных дня.» |

## Если записывать заново

```bash
cd backend && DATA_DIR=./demo-data uvicorn app.main:app --port 8000
```

```bash
cd backend && python scripts/seed_demo_days.py
```

После этого пройти сценарий из таблицы вручную. Плеер Spotify или YouTube должен загрузиться — для этого нужен интернет (при записи в изолированной среде на месте плеера было серое поле).
