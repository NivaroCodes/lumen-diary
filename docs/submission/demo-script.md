## Что в видео не показано

- **Плеер Spotify** в записи пуст: в среде записи нет доступа к `open.spotify.com`, поэтому встраивание не загрузилось. Название трека «U Weren't Here I Really Miss You» видно в блоке «Песня дня» и в форме. Перед показом проверьте плеер на своей машине.
- **YouTube** в видео не используется, серого окна ошибки нет.
- **Песни дней 2 и 3** не выбраны. Их блок в видео не показан.
- **Озвучка** не записана: в среде нет аудио, голос не проверен.
- **Имена Кандинского, Моне и японская минималистичная графика** в подписях не упоминаются: в `art-techniques.md` таких влияний не задокументировано. Если команда их подтверждает, это нужно добавить в документ и подпись отдельно.

## Как записать заново

```bash
cd backend && DATA_DIR=./demo-data uvicorn app.main:app --port 8001
```

```bash
cd frontend && LUMEN_API_TARGET=http://127.0.0.1:8001 npm run dev
```

Затем засеять демо-дни (`python scripts/seed_demo_days.py --url http://127.0.0.1:8001`) и пройти сценарий из таблицы. День «День, парк и солнце» при записи создаётся вручную с текстом «Днём гуляли по парку, всё в жёлтых листьях, пили какао у пруда.»
