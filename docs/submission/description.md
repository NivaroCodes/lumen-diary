# Lumen Diary — описание

## Идея

Lumen Diary — личный дневник, который превращает день в открытку. Пользователь пишет текст, добавляет фотографии и песню, а сервис строит по ним визуальное воспоминание: свет, палитру, фактуру и линию дня. Название дня придумывается системой из записи (3–7 слов) и сохраняется вместе с днём. Сервер хранит дни в отдельных папках, названных по дате и названию дня (например, `2026-11-14 Вечер, комнате и дождь`), и отдаёт список для архива (`GET /api/days`).

Сервис не использует ИИ-модели и внешние API: анализ текста — по словарям, анализ фото — Pillow и NumPy, результат детерминирован (одинаковый ввод даёт одинаковую открытку).

## Аудитория

Не зафиксирована в материалах команды. **Нужно решение команды.** Предлагаемая формулировка: люди, которые ведут личный дневник и хотят возвращаться к своим дням через образ, а не через список записей.

## Как ввод влияет на результат

Правила находятся в `docs/mapping.md`, каждое применение записывается в `explain`.

- **Текст** задаёт время суток (R-LIGHT-01: направление света; R-LINE-01: траектория линии), погоду дождь или туман (R-TEX-01: фактура) и объём записи (R-DEN-01, R-DEN-02: плотность элементов).
- **Фото** задают яркость (R-LIGHT-02: интенсивность света; R-TEX-02: зерно), тепло (R-LIGHT-03: цветовая температура), доминирующие цвета (R-PAL-01: палитра) и контраст (R-PAL-02: насыщенность).
- **Музыка** задаёт темп (R-TEX-03: размытие; R-MOT-01, R-MOT-02: длительность проявки и пульс), энергию (R-LINE-02: амплитуда; R-LINE-03: шероховатость) и лад (R-CON-01: контраст). Файл песни не загружается: пользователь вводит ссылку и фразу о звучании песни («медленная, тихая, с пианино»); темп, энергию и лад система оценивает по этой фразе, а пользователь может уточнить их кнопками «Темп» и «Настроение» вместо ввода чисел. Явный выбор пользователя важнее слов из описания.

## Постоянные элементы

Не меняются ни от дня к дню (`docs/fe-02-visual-spec.md`): рамка фото 936 × 660 px в одном и том же месте, зона даты, подпись «LUMEN DIARY» шрифтом Consolas внизу открытки (в спецификации — сетка листа из 12 колонок).

## Переменные элементы

Палитра (R-PAL-01, R-PAL-02), фактура — зерно, размытие и осадки (R-TEX-01…03), свет (R-LIGHT-01…03), линия дня — траектория, амплитуда, шероховатость (R-LINE-01…03), движение — длительность проявки и пульс (R-MOT-01, R-MOT-02), контраст (R-CON-01).

## Ограничения

- Пасмурная погода (`cloud`) распознаётся, но фактуру не меняет: по правилу R-TEX-01 фактура есть только для дождя и тумана.
- Названия иногда содержат падежные формы («комнате», «совещания»): морфологического анализа в проекте нет, есть только блок-лист слов.
- Рукописная подпись не реализована: подпись — печатный текст.
- Линия дня упрощена: цвет всегда первый из палитры (R-LINE-04), траектория задаётся временем суток из четырёх вариантов.
- Фото третьего дня без людей ещё не получено от пользователя. Озвучки в коде нет; по кейсу она необязательна.
- Оценка темпа, энергии и лада по описанию песни — это оценка по ключевым словам, а не измерение звука; это явно обозначено в интерфейсе.
- Видео на момент этого описания не записано.
