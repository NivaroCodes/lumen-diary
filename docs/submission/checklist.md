# Чек-лист кейса ArtTech

Требования — раздел 07 брифа и комплект сдачи. Статус проверен 22.11.2026 на ветке `claude/quirky-cerf-q9dumf`: тесты, сборка и полный сценарий в браузере (Playwright, Chromium).

| Требование | Как закрыто | Статус |
|---|---|---|
| **07.1** Текст, одно или несколько фото, песня ссылкой | Форма «Новый день»; ссылки Spotify и YouTube; файл песни не принимается | закрыто |
| **07.2** Воспоминание из ввода, без случайного шаблона | Правила R-* (`docs/mapping.md`), детерминизм проверен тестами | закрыто |
| **07.3** Музыка влияет на оформление и звучит при просмотре | Темп → ритм проявки, фото, капель; энергия → размах линии; лад → характер движения. Неизвестный лад показан явно. Плеер Spotify / YouTube на странице дня | закрыто (плеер не проверен вживую: в среде проверки нет интернета) |
| **07.4** Папка дня с коротким названием от системы | `2026-11-12 Утро, чай и дождь`; имя папки видно на странице дня и в архиве | закрыто |
| **07.5** Архив с возвратом к любому дню | Экран «Архив» по месяцам; открытие дня проверено в браузере | закрыто |
| **07.6** Единая визуальная система, три дня с разным настроением | Cormorant Garamond + Manrope, 12 колонок, фиксированные дата и подпись; три демо-дня (`media/postcard-*.jpg`) | закрыто |
| **07.7** Собственный вклад, раскрытие библиотек и ИИ | `docs/tools.md` с лицензиями; эффекты написаны командой | закрыто |
| **07.8** Проверка по инструкции или видео | `backend/README.md`, `docs/submission/clean-run.md`, видео `media/demo.mp4` | закрыто |
| Видео до 3 минут | `media/demo.mp4`, 83 с, без звука | закрыто (озвучку поверх можно добавить) |
| Примеры дней с названиями папок | `examples/demo-*.json` (три демо-дня), `examples/day-*.json` (фикстуры) | закрыто |
| Описание до 1 страницы | `description.md` | закрыто |
| Художественные приёмы | `art-techniques.md` | закрыто |
| Погода и место вручную (приоритет 2) | Кнопки погоды и поле места; без внешних API | закрыто |
| Озвучка записи (приоритет 3) | Кнопка «Прочитать запись вслух», `speechSynthesis` | сделано; звук не проверен (в среде проверки нет аудио) |

## Решения команды, которые остаются

1. Аудитория: формулировка в `description.md` — предложение.
2. Заголовки без морфологии: демо-тексты подобраны так, чтобы слова стояли в именительном падеже.
3. Ссылки на песни демо-дней (`seed_demo_days.py`) не проверены вживую — проверить перед показом.
